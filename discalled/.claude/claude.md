# 📑 프로젝트 기획 및 설계 명세서

## 1. 프로젝트 개요 (Project Overview)

### 1.1 배경 및 문제 정의

- **컨텍스트 스위칭의 불편함:** 게이머나 개발자가 몰입하여 플레이/작업을 수행하는 도중, 모르는 정보나 에러를 검색하기 위해 창을 전환(Alt + Tab)하는 행위는 작업 흐름과 몰입감을 깨뜨리는 주요 원인입니다.
- **기존 봇의 한계:** 현재 상용화된 대부분의 디스코드 AI 봇은 텍스트 명령어 기반이거나, 음성 채널 전체를 무겁게 실시간 녹음하는 회의록 작성용 봇에 치중되어 있어 가벼운 '음성 비서' 역할을 수행하기 어렵습니다.

### 1.2 솔루션 정의

- **discalled:** 유저가 필요할 때만 호출하여 음성으로 질문을 던지고, AI가 실시간 웹 검색을 거쳐 요약된 결과를 디스코드 메시지로 전달한 후 즉시 퇴장하는 **'컨텍스트 유지형 게이밍/작업 컴패니언 음성 비서 봇'**입니다.

### 1.3 핵심 기술 스택

- **Runtime & Language:** Node.js, TypeScript
- **Discord API:** discord.js, @discordjs/voice
- **AI Engine (xAI API):**
  - grok-speech-to-text (음성 분석 및 텍스트 변환)
  - grok-2-latest (웹 검색 툴이 통합된 실시간 검색 및 요약 LLM)
- **Audio Processing:** libsodium-wrappers, opusscript, Node.js Stream API

## 2. 프로젝트 목표 (Project Goals)

### 2.1 기능적 목표 (Functional Goals)

- **온디맨드(On-Demand) 음성 호출:** 슬래시 명령어 /호출 입력 시 유저가 속한 음성 채널에 즉각 입장하며, 입장/퇴장 시 사운드 피드백(효과음)을 제공하여 시각적 확인 없이도 상태를 인지할 수 있도록 합니다.
- **지능형 침묵 감지 (VAD: Voice Activity Detection):** 유저가 말을 시작한 후 약 1.5~2초간 음성 신호가 없으면 자연스럽게 발화가 끝난 것으로 판단하고 녹음을 자동 마감합니다.
- **자연어 명령 파싱:** 변환된 텍스트에서 후미 접사(~검색해줘, ~찾아줘)를 파싱하여 순수 검색 쿼리만 정제합니다.
- **실시간 웹 검색 및 3줄 요약:** xAI의 내장 web_search 도구를 활용해 최신 정보(게임 공략, 에러 로그 등)를 검색하고, 디스코드 가독성에 최적화된 형태로 3줄 요약하여 Rich Embed 메시지로 전송합니다.
- **텍스트 검색 명령어 지원 (Fallback):** 음성을 사용하기 어려운 환경을 고려하여 텍스트 채널에서 즉시 검색할 수 있는 /검색 명령어 인터랙션을 병행 제공합니다.

### 2.2 비기능적 목표 (Non-Functional Goals)

- **비용 및 리소스 최적화:** 24시간 음성 대기 방식을 탈피하고 **'호출 ➔ 인식 ➔ 퇴장'** 시나리오를 채택하여, 서버 자원 낭비를 방지하고 무분별한 API 호출 비용을 최소화합니다.
- **안정적인 타입 시스템 구축:** discord.js 내부의 복잡한 이벤트 및 오디오 스트림 데이터 타입을 엄격하게 정의하여 런타임 에러를 사전에 차단합니다.
- **모듈화 및 확장성:** 음성 처리 로직(Audio), AI 추론 로직(Grok), 디스코드 이벤트 핸들러를 철저히 분리하여 향후 다른 AI 모델로의 교체가 용이하도록 설계합니다.

## 3. 디렉토리 구조 (Directory Structure)

프로젝트의 확장성과 유지보수성을 극대화하기 위해 **기능 중심(Feature-based) 및 레이어드 아키텍처(Layered Architecture)**를 절충한 구조를 채택합니다.

```text
discalled/
├── .env                      # API Key, 디스코드 봇 토큰 등 보안 환경변수
├── .gitignore
├── nodemon.json              # 개발 환경 파일 변경 감지 및 ts-node 재시작 설정
├── package.json
├── tsconfig.json             # 절대경로 배럴 구성 및 타입스크립트 컴파일러 옵션
│
├── src/
│   ├── index.ts              # 애플리케이션 진입점 (Client 빌드 및 가동)
│   ├── config.ts             # 환경변수 타입 검증 및 읽기 전용 export
│   │
│   ├── @types/               # 프로젝트 전역 커스텀 타입 정의
│   │   └── index.d.ts        # 오디오 버퍼 및 세션 관련 타입 선언
│   │
│   ├── events/               # 디스코드 클라이언트 이벤트 핸들러
│   │   ├── ready.ts          # 봇 구동 및 슬래시 명령어 글로벌 등록 이벤트
│   │   └── interactionCreate.ts # 슬래시 명령어 분기 및 실행 핸들러
│   │
│   ├── commands/             # 슬래시 명령어 정의 레이어
│   │   ├── index.ts          # 명령어 컬렉션 내보내기 (Export 배럴)
│   │   ├── search.ts         # /검색 : 텍스트 기반 즉시 검색 명령어
│   │   └── call.ts           # /호출 : 음성 채널 입장 및 녹음 트리거 명령어
│   │
│   ├── services/             # 코어 비즈니스 로직 레이어 (외부 API 및 가공)
│   │   ├── grok.ts           # xAI SDK 연동 (Transcriptions 및 Chat Completion 컴포넌트)
│   │   └── audio.ts          # 오디오 스트림 수신, PCM 믹싱, WAV 변환 및 VAD 제어
│   │
│   ├── utils/                # 공통 유틸리티 함수
│   │   ├── embed.ts          # 디스코드 Rich Embed 템플릿 생성기 (성공/에러 UI)
│   │   └── logger.ts         # 개발 및 운영 로그 기록기 (콘솔 출력 가독화)
│   │
│   └── assets/               # 정적 리소스 폴더
│       ├── entry.mp3         # 봇 입장 시 재생되는 사운드 피드백
│       └── exit.mp3          # 음성 인식 마감 및 퇴장 시 재생되는 사운드 피드백
```
