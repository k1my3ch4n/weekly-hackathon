# 🎙️ Discord AI English Tutor Bot (프로젝트 기획서)

## 1. 프로젝트 개요

본 프로젝트는 사용자가 디스코드(Discord) 음성 채널에서 인공지능과 실시간으로 대화하며 영어 회화를 연습할 수 있는 **인공지능 기반 디스코드 영어 회화 튜터 봇**입니다.

초고속 추론 엔진인 **Groq API(Llama 3, Whisper)**를 사용하여 음성 인식(STT) 및 답변 생성(LLM)의 딜레이를 최소화하고, 이를 디스코드의 인터페이스(채팅, 음성, 버튼 컴포넌트)와 결합하여 자연스럽고 몰입감 있는 회화 환경을 제공합니다. 별도의 복잡한 데이터베이스 서버 구축 없이, 로컬 개발 환경 및 경량 인프라에서 효율적으로 구동되도록 설계되었습니다.

---

## 2. 프로젝트 목표

- **실시간성 확보**: Groq API의 장점을 극대화하여 유저의 말이 끝난 후 1.5초 이내에 텍스트 변환 및 AI 답변 생성이 시작되도록 프로세스를 최적화합니다.
- **사용자 친화적 오디오 흐름(Audio UX) 구현**:
  - 유저의 음성 입력을 실시간으로 감지(Silence Detection)하여 텍스트로 채팅창에 출력합니다.
  - AI의 답변을 음성 채널로 송출함과 동시에, 채팅창에 텍스트 및 **[다시 듣기 🔁]** 상호작용 버튼을 제공합니다.
- **유연한 대화 컨텍스트 유지**: 세션(Session) 개념을 도입하여 봇이 켜져 있는 동안 유저별 이전 대화 기록을 완벽하게 기억하고 문맥에 맞는 대화를 이어갑니다.
- **유지보수성이 높은 아키텍처 구축**: 확장하기 까다로운 기존 디스코드 봇의 모놀리식 구조에서 벗어나, 프론트엔드에서 검증된 **Feature-Sliced Design(FSD)** 패턴을 도입하여 기능 단위로 결합도를 낮추고 확장성을 높입니다.

---

## 3. 디렉토리 구조 및 코딩 규칙

### 📁 디렉토리 구조 (Feature-Sliced Design 패턴 기반)

디스코드 봇 환경에 맞게 FSD 패턴을 재해석하여 적용했습니다. UI 레이어가 중심이 되는 웹과 달리, 디스코드 봇은 **이벤트(Events)**와 **명령어(Commands)**, **음성 처리 스트림(Streams)**이 중심이 되므로 각 레이어를 다음과 같이 정의합니다.

```
src/
├── app/                  # 앱 초기화, 디스코드 클라이언트 설정 및 메인 진입점
│   ├── index.ts          # 봇 실행 메인 스크립트
│   └── config.ts         # 환경 변수 및 글로벌 설정
│
├── processes/            # 여러 기능(Features)이 복합적으로 얽힌 비즈니스 프로세스
│   └── voiceConversation/ # 음성 수신 -> STT -> LLM -> TTS -> 음성 송출로 이어지는 전체 흐름 제어
│
├── pages/                # (웹 프론트엔드가 아니므로 봇 환경에서는 생략하거나 대시보드 필요 시 활용)
│
├── features/             # 비즈니스 가치를 가지는 사용자 상호작용 기능 단위 (핵심 레이어)
│   ├── audio-recorder/   # 유저 음성 스트림 감지 및 파일 인코딩 (PCM to WAV)
│   ├── stt-transcriber/  # Groq Whisper API 연동 및 텍스트 변환
│   ├── ai-chat/          # Groq Llama 3 API 연동 및 대화 컨텍스트 생성
│   └── tts-speaker/      # OpenAI/ElevenLabs TTS 연동 및 디스코드 음성 송출
│
├── entities/             # 도메인 모델 및 상태 관리 (비즈니스 엔티티)
│   ├── user/             # 유저 데이터 구조 정의
│   └── session/          # 대화 히스토리 및 세션 관리 (Zustand Store 위치)
│       ├── model/
│       │   └── sessionStore.ts
│       └── index.ts
│
├── shared/               # 프로젝트 전반에서 재사용되는 인프라 및 유틸리티
│   ├── api/              # Groq, OpenAI 등 외부 SDK 클라이언트 인스턴스화
│   ├── utils/            # ffmpeg 래퍼, 시간 포맷터 등의 순수 함수
│   └── types/            # 글로벌 타입 정의
```

- 상태관리 도구로 zustand 사용
- FSD 구조 세팅
- tanstack query ( 필요하다면 사용 )
